# Feisty Unicorn Coffee House — Static Preview

This folder contains a drop-in static HTML preview of the Feisty Unicorn Coffee House experience. It mirrors the WordPress + Shopify builds so you can open everything instantly without installing a CMS.

## Contents

- `index.html` – Single-page site with hero, drinks, merch, partner lineup, events, testimonials, and the arcade mini-game.
- `assets/css/theme.css` – Brand styling shared with the WordPress theme.
- `assets/js/theme.js` – Navigation toggle, testimonial slider, and canvas arcade runner.
- `assets/images/` – Placeholder artwork for hero, drinks, and merch tiles.

## Quick preview

1. Download or clone this repository.
2. Open `feisty-unicorn-static/index.html` directly in your browser (double-click from Finder/Explorer or drag it into Chrome/Safari).
3. The arcade mini-game works locally; tap/click the canvas or press the space bar to jump.

No build tools or servers are required—the HTML file is ready for immediate sharing or lightweight hosting (Netlify Drop, GitHub Pages, etc.).
